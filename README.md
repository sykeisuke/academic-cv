# Keisuke Yoshihara - Academic CV

This repository contains the LaTeX source and generated PDF for the academic CV.

## Build

```bash
make
```

The PDF is written to `output/Keisuke_Yoshihara_Academic_CV.pdf`.

## Files

- `academic_cv.tex`: current editable source
- `assets/`: logo and other source assets
- `output/`: generated PDF
- `source_original/`: archived source used to start this version
